# رفيق لينكدإن · Rafeeq

أدوات مجانية مفتوحة المصدر تساعد مستخدمي لينكدإن على الكتابة والتحقق وحماية بياناتهم، وتعمل **بجانب** المنصة لا داخلها.

> رفيق مشروع مستقل، لا يرتبط بلينكدإن ولا تعتمده.

## المبدأ الحاكم

تحظر سياسة لينكدإن البرمجيات والإضافات التي تكشط بيانات موقعها أو تغيّر مظهره أو تؤتمت النشاط عليه، ولذلك يلتزم رفيق بما يلي:

- **لا كشط ولا أتمتة**: لا يقرأ صفحات لينكدإن ولا يرسل أي طلب إليها.
- **المستخدم هو من ينسخ وينشر**: المدخلات نص يلصقه المستخدم، أو ملف تصدير بياناته الرسمي.
- **المعالجة محلية**: التطبيق ملف HTML واحد يعمل داخل المتصفح، بلا خوادم ولا تتبع.
- **النشر الآلي**، إن أُضيف مستقبلاً، يمر فقط عبر واجهات لينكدإن الرسمية بعد الحصول على موافقتها.

## المكونات

### 1. تطبيق الويب: `app/index.html`

| الأداة | ما تفعله |
|---|---|
| فاحص الاحتيال الوظيفي | يقيس مؤشرات الاحتيال في رسائل التوظيف (رسوم مسبقة، واتساب، عملات رقمية، «وظائف مهام»…) على مقياس من 0 إلى 10 |
| فاحص الخصوصية | يكشف الهوية والإقامة والجوال والآيبان والبطاقات والجواز وسطور MRZ، وينتج نسخة مُقنّعة. يطمس أجزاء الصور ويحذف بيانات EXIF |
| مدقق المنشور | الطول من 3,000 حرف، وما يظهر قبل «…المزيد»، والوسوم، والفقرات الطويلة، والخاتمة |
| مولّد الشرائح العربية | يحوّل النص إلى شرائح PDF عربية سليمة الاتجاه (4:5 أو 1:1) جاهزة للرفع كمستند |
| محلل الشبكة | يقرأ `Connections.csv` من تصديرك الرسمي: النمو، والجهات، والأدوار، وأفكار عملية |

**التشغيل**: افتح `app/index.html` في أي متصفح، أو انشره على GitHub Pages (يوجد سير عمل جاهز في `.github/workflows`). يحتاج التطبيق إلى الإنترنت فقط لتحميل خط IBM Plex Sans Arabic من Google Fonts، ويعمل بخط النظام إن لم يتوفر.

عند تشغيله داخل Claude كـ Artifact، تظهر أزرار إضافية للذكاء الاصطناعي: رأي ثانٍ في الاحتيال، والاختصار، وافتتاحية أقوى، والترجمة.

### 2. إضافة Claude: `skills/`

| المهارة | الاستخدام |
|---|---|
| `job-scam-check` | تحليل رسالة توظيف واقتراح رد وخطوات تحقق |
| `privacy-check` | فحص نص أو وثيقة أو صورة قبل النشر |
| `linkedin-post-studio` | كتابة المنشورات ومراجعتها واختصارها وترجمتها، وتحويلها إلى شرائح |
| `profile-optimizer` | العنوان المهني والنبذة والخبرات والمهارات بالعربية والإنجليزية |
| `job-match` | مطابقة السيرة مع الوظيفة، وخطاب التقديم، وأسئلة المقابلة |
| `linkedin-messages` | الرسائل والردود والاعتذار وطلب التوصيات وكتابتها |
| `network-insights` | تحليل ملف التصدير الرسمي للشبكة |

**التثبيت في Claude Code**: المستودع نفسه سوق إضافات (marketplace).

```
/plugin marketplace add <owner>/rafeeq      # بعد رفعه إلى GitHub، أو مسار المجلد المحلي
/plugin install rafeeq@rafeeq
```

**في تطبيق Claude**: ارفع ملف rafeeq.zip من إعدادات الإضافات، إن كان ذلك متاحاً في حسابك.

ملفات `SKILL.md` نصوص Markdown عادية، يمكن استخدامها مع أي مساعد ذكاء اصطناعي كتعليمات نظام.

## English summary

Rafeeq is a free, open-source toolkit for LinkedIn members, Arabic-first. It works beside LinkedIn: it never scrapes, automates or modifies LinkedIn pages. You paste text or load your own official data export, and you post by hand.

- **Web app** (`app/index.html`, single file, runs locally): job-scam checker, privacy checker with image redaction, post checker, Arabic RTL carousel-to-PDF generator, and a network analyzer for `Connections.csv`.
- **Claude plugin** (`skills/`): seven skills covering scams, privacy, posts, profiles, job matching, messages and network insights.

Run the tests with `node tests/core.test.mjs`. MIT licensed.
