## المراحل

- **المرحلة 1 (منجزة):** الاحتيال، والخصوصية، والمنشور، والشرائح، والشبكة، مع سبع مهارات.
- **المرحلة 2 (منجزة، v0.2):** تبويبا «مراجع الملف الشخصي» و«مطابق الوظيفة»، وقراءة ZIP التصدير مباشرة مع Shares.csv وProfile.csv وPositions.csv، وأنماط بيانات حساسة للإمارات ومصر والكويت وقطر والبحرين وعُمان والأردن، وآيبان عربي بتحقق mod 97.
  - متبقٍ مقترح: تحليل Invitations.csv (نسبة الدعوات الشخصية)، وأنماط المغرب العربي وأرقام الهوية العراقية واللبنانية بعد توثيقها.
- **المرحلة 3:** مسارات التعلم المرتبطة بالأطر الوطنية (NORA وNDMO وDGA)، وفتح المساهمات المجتمعية، والإطلاق عبر منشور ومحاضرة توعوية.
